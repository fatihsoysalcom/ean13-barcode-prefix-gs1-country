# EAN13 Barcode Prefix GS1 Country

This example Python script demonstrates the true meaning of an EAN-13 barcode's prefix. It debunks the common misconception that the first few digits indicate the product's country of manufacture. Instead, the script shows that these prefixes identify the country of the GS1 Member Organization that assigned the barcode number, highlighting the complexities of global supply chains.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt in the same directory and run:
`python main.py`
